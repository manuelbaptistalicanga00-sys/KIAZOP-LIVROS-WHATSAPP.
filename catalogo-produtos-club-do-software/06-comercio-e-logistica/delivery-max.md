# Delivery Max

**Categoria:** 06 Comercio E Logistica
**Pasta Drive:** [Delivery Max](https://drive.google.com/drive/folders/1dYWZrXfhq3WLarFbxVj4L6ACrNVkDh83)

## Resumo

Sistema de pedidos e entregas para restaurantes. O README do pacote descreve catálogo/carrinho para clientes, dashboard administrativo, quadro Kanban de pedidos, produtos, entregadores/regiões e PDV; a stack inclui React/TypeScript/Supabase.

## Público potencial

Restaurantes, takeaways e operadores de entrega local.
