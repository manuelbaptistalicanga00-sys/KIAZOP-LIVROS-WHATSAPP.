# Service PRO

**Categoria:** 04 Juridico E Servicos
**Pasta Drive:** [Service PRO](https://drive.google.com/drive/folders/16MBQthkTvyNQyfeQv_JQVSTJcUs_yDBQ)

## Resumo

Aplicação web de ordens de serviço para empresas de assistência técnica. O README descreve clientes, técnicos, tipos de serviço, ordens de trabalho, estatísticas e impressão de ordens; usa Supabase/PostgreSQL segundo a documentação.

## Público potencial

Técnicos, oficinas e empresas de reparação/manutenção.
