# FusiON

**Categoria:** 03 Ia E Automacao
**Pasta Drive:** [FusiON](https://drive.google.com/drive/folders/12nQjx0cy3oMqbwkMNE9_qNJ_CUOUHDE3)

## Resumo

Aplicação web de desenho visual de fluxos para agentes de IA: adicionar agentes especializados, ligar etapas num canvas, configurar cada agente e executar o fluxo. A descrição técnica do README indica React/TypeScript e componentes de workflow.

## Público potencial

Agências de automação e equipas que querem prototipar workflows com vários agentes.
